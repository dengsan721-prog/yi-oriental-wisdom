- 模板共 `7,121` 个字符记录；文本“命”和 U+547D 唯一命中记录 `_pbnNEZ4qVAULE1LPSA54`。
- 该记录含 `8` 个笔画。使用 FontPlayer v0.4.1 自带的“字玩标准隶书（仅笔画）”和“风格切换”生成，转换后八个笔画均核对为隶书笔画。
